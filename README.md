# Capital PM - Control de Asistencia

PWA de control de asistencia con geolocalización para Capital PM.

## Funcionalidades
- Registro de entrada/salida con geolocalización
- Validación de geocerca configurable
- Modo offline con sincronización automática
- Panel administrador en tiempo real
- Exportación de reportes CSV

## Instalación local
```bash
npm install
npm run dev
```

## Deploy
Conectar repositorio a Vercel. Build automático con cada push.
